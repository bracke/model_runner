# Predeclared real Ada transfer evaluation

Declared 2026-11-24 before any model attempt in this evaluation. The previous Mellum training, selected
epoch-six adapter and merged weights are frozen. No new fitting, selection or sampling adjustment is allowed.

This is historical task replay on dependency-bearing source snapshots from actual local repositories,
not a claim to evaluate an unseen private backlog or entire applications. Each actor receives the complete
tracked `src` tree at the parent of a pinned historical change, plus a small build main and public checks.
Reference controls replace only permitted target files with their versions from that historical change.
The six tasks and their fixes are excluded from the adapter's five-family teaching corpus and prior
Add/Times/Subtract evaluation. Model pretraining exposure is unknown.

Freeze the task instructions, public and independent test hashes, entire initial source-tree identities,
parent commits, executable, driver, compiler, models, configuration and this protocol in a manifest before
generation. Qualify all six unchanged controls as failing and all six historical reference controls as passing.
The Boolean API task is a real two-file addition: its starting smoke main builds, while checks requiring
the missing API fail compilation until that feature exists. The other tasks start with behavioral failures.

Independent checks include cases not present in the actor's public checks. The grader preserves the public
test, forces a fresh build of its protected independent main in separate storage, and requires the submitted
diff to remain within exact permitted source paths. Public test changes, unrelated edits and symlink outputs
fail. Qualify scope enforcement and test preservation, plus actual operating-system confinement. Hide the
entire original Ada workspace from each actor, including upstream fixed sources, reference controls, sibling
attempts, driver and reports. Rebind only its writable project, model, executable, configuration and native
runtime resources. Use pinned Alire GNAT 15 and Ada 2022 for both public and independent compilation.

Run tasks in the table's order, each at seeds **71 and 72**, with both **base and adapted** arms: **12 pairs,
24 attempts**. Alternate arm order using task index plus seed parity. Runs are serial. Use the same corrected
production harness and the user's unchanged inference defaults; only the seed and model differ. Thinking
and effort remain unforced, carried knowledge is off, and every attempt gets **600 work seconds** with
the existing 300-second startup bounds. An outer 1,200-second child limit is infrastructure protection,
not additional model work. Complete repository builds and checks before generation; no builds or tests
unrelated to the active task run alongside inference.

Native completion followed by independent passing tests, exact scope and unchanged project configuration
is a pass. All timeouts, rejected completion reports, incorrect patches and compile failures remain failures;
retain them without replacement or repair. Keep infrastructure errors distinct and preserve their evidence.
Diagnose infrastructure before continuing missing planned attempts; never convert an existing failure to a pass.

After all 24 attempts, report every grade, per-task and per-model totals, paired wins/losses, matching
settings and source identities, generated tokens, calls and work time. Compare efficiency only within pairs
both models solve; retain all-attempt costs separately. Rebuild final sources of failed workflows separately
when possible, without upgrading the original grade. Report limitations of six task families, two seeds,
three repositories, historical replay, a common machine, one small output-only adapter and shared test cases.
An exact paired sign calculation may describe discordant outcomes but does not remove those limitations.
No automatic default-model change or generalized reliability claim is authorized by this study.
