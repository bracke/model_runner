# Embedding inference

`Model_Runner.Inference` is the supported in-process boundary for callers that need one bounded completion without the
CLI. It owns the GGUF shards, parsed container, prepared model, worker pool, and reusable generation session. Closing or
finalizing the session releases those resources in dependency order.

`Open` accepts only a local model path and explicit `Open_Options`. Expected loading, validation, preparation, and
session failures are returned as `Model_Runner.Errors.Error_Info`. The package does not resolve aliases, download a
model, write diagnostics, or interact with model_runner task state.

`Complete` resets the generation context for each request, converts the supplied JSON Schema to a grammar, compiles it,
and constrains generation with that grammar. `Completion_Options` supplies the absolute cooperative deadline, token
limit, byte limit, and sampling policy. Generated bytes are captured through a bounded sink; a completion cannot retain
or return more than `Maximum_Output_Bytes`.

The result distinguishes a normal engine completion, an expired deadline, output-limit closure, and a typed engine or
schema failure. `Maximum_Tokens` and other ordinary completion reasons do not assert that the returned text is a
complete JSON document. An embedding must parse the text into its own typed response and treat incomplete or invalid
data as a malformed response.

The session is single-owner and `Complete` runs synchronously on the calling task. A caller may reuse it sequentially,
but must not call it concurrently or asynchronously abort it while the engine owns resources.
